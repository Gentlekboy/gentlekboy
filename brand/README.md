# Brand mark — "K" monogram

Concept: `!` (CSS "important") + `<` (opening a tag) fused into the letter
"K", the first letter of Kufre's name. Three iterations, each for a
different context.

| File | Use |
|---|---|
| `fused-k.svg` | **In active use.** Spine and arms touch, reads as K at any size. Used as the site favicon/app icon (`app/icon.tsx`) and the nav wordmark icon (`components/Nav.tsx`). |
| `bracket-forward.svg` | Reserve. Closer to the original concept — `!` and `<` stay visibly separate — reads clearly only at large sizes. Good for an about-page illustration, printed resume header, or business card, not for anything small (nav, favicon, tab). |
| `monoline-companion.svg` | Reserve. Same structure as `fused-k.svg` at a lighter stroke weight (8 vs 14), for pairing with the wordmark somewhere a bold mark would feel heavy. Too thin for the favicon. |

All three use flat `#E8A144` (the site's `--accent` token) on a transparent
background — no gradients — so they drop onto any surface in the design
system without adjustment.
